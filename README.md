<h1>Kaustubh Bane</h1>

<p><strong>Product Engineer at Digital Health Associates | Next.js, React Native &amp; AI-Powered Applications | 7× Hackathon Winner</strong></p>

<p>I build web and mobile apps end to end, from the interface to the APIs, the database, and the integrations around them. The work covers AI agent workflows, search and retrieval, authentication, role-based access, content management, and product analytics. I do that on new products and on systems that already exist.</p>

I build and maintain Next.js sites, including the International Patients' Union website, and I contribute to the IPU mobile app in React Native. The wider work includes newsletters, dashboards, and other digital-health products.</p>
